              Aucune copie. Déposez une source, choisissez un préréglage, puis « Ajouter à la file ».

              Eilañ

              « eilañ » : « copier » en breton. Copie de rushs vers une ou plusieurs destinations, avec vérification par empreinte (xxHash64 ou MD5) et rapport.

              Réglages

              Le rapport est écrit dans chaque destination, à la fin de chaque copie.

              ffmpeg est introuvable : le rapport sera écrit sans vignettes. Installez-le (par exemple « brew install ffmpeg ») ou lancez « npm install ».

              Dossier des préréglages
              Les préréglages sont lus et enregistrés dans ce dossier. Pointez-le vers un dossier partagé pour les retrouver sur plusieurs ordinateurs.
